# Black Friday in Iran: Data Analysis (2021–2025)

## Project Overview

This project explores the evolution of Black Friday awareness and consumer-related search behavior in Iran between 2021 and 2025.

The main objective is to investigate how public interest in Black Friday has changed over time and examine its potential relationship with broader economic conditions and the development of e-commerce in Iran.

The analysis combines data from multiple sources to identify patterns, trends, and potential relationships between consumer behavior and economic indicators.

## Research Questions

- How has public interest in Black Friday evolved in Iran between 2021 and 2025?
- How concentrated is search interest around the Black Friday season?
- What patterns can be observed in yearly and seasonal search trends?
- How might economic indicators relate to changes in consumer interest?
- What role might the development of e-commerce play in this trend?

## Important Note

Google Trends data represents normalized search interest on a scale from 0 to 100, rather than absolute search volumes.

Therefore, changes in this index should not be interpreted as equivalent changes in the actual number of searches.
